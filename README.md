
# 📚 Информационно-поисковая система «Расписание занятий»

> Проект по дисциплине «Программная инженерия».

---

## 📖 О проекте

**Информационно-поисковая система «Расписание занятий» (ИПС «Расписание занятий»)** — программная система, предназначенная для хранения, поиска и предоставления информации об учебном расписании студентов и преподавателей.

Проект направлен на упрощение доступа к сведениям об учебных дисциплинах, преподавателях, аудиториях, учебных группах и времени проведения занятий.

## 🎯 Цель проекта

Создание информационно-поисковой системы, обеспечивающей удобный и быстрый поиск актуальной информации о расписании занятий, а также предоставление пользователям необходимых сведений для организации учебного процесса.

## ⚙️ Основные функции

- 📅 Просмотр расписания по дням недели.
- 🗓️ Просмотр расписания на неделю.
- 👨‍🏫 Получение информации о преподавателях.
- 🏫 Получение информации об учебных аудиториях.
- 👥 Просмотр расписания для определённой учебной группы.

## 👥 Пользователи системы

1. **Студент**
   - Просмотр расписания своей учебной группы.
   - Поиск занятий.
   - Просмотр информации о преподавателях, дисциплинах и аудиториях.

2. **Преподаватель**
   - Просмотр собственного расписания.
   - Просмотр информации о проводимых занятиях и аудиториях.

3. **Администратор**
   - Управление информацией о расписании.
   - Добавление и редактирование учебных дисциплин.
   - Управление сведениями о преподавателях и аудиториях.
   - Обновление информации об учебных группах и занятиях.

## 📌 Особенности проекта
